04_autorize

Включение режима storage (хранение в localStorage)

config.php:
- corsCredentials = false
- tokenNode = 'header'
в JS:
const session = new Session(request,{
mode:'local',
storage:'local' // 'session'
})


Включение режима httpOnly (хранение coockie на сервере)

config.php:
- corsCredentials = true
- tokenNode = 'cookie'
в JS:
const session = new Session(request,{
mode:'cookie',
storage:'local' // 'session'
})
