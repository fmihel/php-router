04_authorize

Включение режима storage (хранение в localStorage)

config.php: 

    corsCredentials = false
    tokenMode = 'header'
в JS: 

    const session = new Session(request,{
            mode:'local',
            storage:'local'// session
    });
Включение режима httpOnly (хранение cookie на сервере)

config.php: 

    corsCredentials = true
    tokenMode = 'cookie'
в JS: 

    const session = new Session(request,{
        mode:'cookie',
        storage:'local' // 'session'
    })
